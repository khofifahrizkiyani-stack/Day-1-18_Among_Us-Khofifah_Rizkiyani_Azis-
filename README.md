# Deskripsi singkat mengenai repository.
Repository GitHub adalah tempat penyimpanan proyek atau kode program di platform GitHub. Repository digunakan untuk menyimpan, mengelola, dan mengembangkan file proyek, serta mencatat setiap perubahan kode yang dilakukan.

# Tujuan atau kegunaan repository.
- Menyimpan kode program: Menjadi tempat penyimpanan file dan kode dari suatu proyek.
- Mengelola proyek: Membantu mengatur file agar lebih rapi dan mudah ditemukan.
- Mencatat perubahan: Menyimpan riwayat perubahan kode sehingga pengguna dapat melihat perkembangan proyek.
- Kolaborasi: Memungkinkan beberapa orang bekerja sama dalam satu proyek.
- Berbagi proyek: Memudahkan pengguna membagikan kode program kepada orang lain.

# Catatan atau rangkuman materi yang diperoleh.
Prompt Engineering merupakan cara menyusun instruksi agar AI menghasilkan jawaban yang tepat dan sesuai kebutuhan.  Promt perlu diberikan konteks agar hasil yang dihasilkan dapat lebih sesuai. Tanpa kontes yang jelas AI akan melakukan pekerjaannya tanpa batasan yang kita berikan. Tapi promt dengan konteks tak selamanya lebih bagus, karena tanpa alur kerja yang baik, AiI bisa saja kebingungan dan hasil yang dihasilkan kurang memuaskan. Untuk itu kita memerlukan AI Engineering untuk membuat promt yang baik. Urutan Pembuatan Promt adalah sebagai berikut: 
1.	Role 
2.	Tugas 
3.	Content 
4.	Format
   
Keuntungan promt engineering 
1.	meningkatkan performa ai 
2.	mengurangi bias dan respon yang devensive 
3.	meningkatkan control dan prodictibility 
4.	memberikan pengalaman yang lebih baik.

Git adalah version control system yang melayak siapa, kapan, dan apa saja yang sudah dirubah dalam suatu file. Git diciptakan oleh  Linus Torvalds yang pada awalnya ditujukan untuk pengembangan kernel Linux. Github adalah platform yang menyediakan ruang penyimpanan kode (repository) dan memanfaatkan Git sebagai sistem kontrol versi untuk mencatat setiap perubahan kode. Dalam Git Workflow terdapat tiga bagian utama, yaitu Working Directory sebagai tempat mengerjakan proyek, Staging Area sebagai tempat menyiapkan perubahan, dan Git Directory sebagai tempat menyimpan informasi proyek. Penggunaan Git melibatkan beberapa perintah seperti git init, git add, git commit, git push, git pull, dan git clone. Selain itu, diperlukan pengaturan Git, VS Code, serta SSH Key untuk menghubungkan komputer dengan GitHub.
